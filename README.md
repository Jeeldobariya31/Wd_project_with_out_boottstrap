# 🇮🇳 Incredible India - Interactive Web Project

## 🏵️ Overview
**Incredible India** is a beautifully designed static website that showcases the vibrant culture, cuisine, landmarks, and diversity of India.  
This project is created using **HTML5**, **CSS3**, and **Font Awesome**, integrating animations, interactive forms, videos, and a dynamic navigation system for an immersive user experience.

## 🏠 Home Page (`home.html`)
- Welcomes visitors with animated headings and a clean layout.
- Highlights:
  - Overview of India’s diversity and beauty.
  - Images and details about **landmarks**, **culture**, and **food**.
  - Links to explore deeper sections of the website.
- Navigation links:
  - Home | Culture | Landmarks | Cuisine | Contact Us

---

## 🎭 Culture Page (`culture.html`)
- Explores the **diverse traditions** of India.
- Sections include:
  - **Festivals** – Diwali, Holi, Eid, Christmas.
  - **Languages** – Displays an HTML table of Indian languages and their regions.
  - **Traditional Attire** – Highlights saree, kurta-pajama, lehenga, and dhoti.
- Incorporates images and descriptive text for easy understanding.

---

## 🏰 Landmarks Page (`landmarks.html`)
- Showcases India's **historical and geographical marvels**.
- Sections include:
  - **Iconic Monuments:** Taj Mahal, Red Fort, Hawa Mahal, Charminar.
  - **Indian States & Capitals:** Detailed table with area and language data.
  - **Fun Facts:** Floating post office in Dal Lake, Srinagar.
- Designed with tables and images to make content informative and visual.

---

## 🍛 Cuisine Page (`cuisine.html`)
- A delicious journey through **Indian culinary traditions**.
- Categorized sections:
  - **North Indian Dishes:** Biryani, Butter Chicken, Paneer Tikka.
  - **South Indian Dishes:** Masala Dosa, Idli-Sambar, Chettinad Chicken.
  - **Sweets:** Gulab Jamun, Rasgulla, Payasam.
- Includes images and an embedded **audio file** (`titanium.mp3`).
- Navigation consistent with the rest of the site.

---

## 📩 Contact Us Page (`contactus.html`)
- Interactive **Student Registration Form** with the following fields:
  - Name, Father’s Name, Surname, Password (8-digit), Gender, State, Resume Upload, Address, DOB, Interview Time, Marks.
- Includes:
  - Validation patterns for inputs.
  - Embedded **OJAS job opportunities frame**.
  - Direct email link: `info@incredibleindia.com`
  - Footer credits and social media links.
- Additional “Dance Time” button linking to the fun **dance.html** page.

---

## 💃 Dance Page (`dance.html`)
- Fun, interactive page with **concert light effects** and a **background video**.
- Includes:
  - Start/Stop buttons for glowing light animations.
  - Background video: "_Abhi Toh Party Shuru Hui Hai_" song.
  - Navigation link to go **Back to Home**.
- CSS animations in `dancing light.css` bring the party vibe alive!
